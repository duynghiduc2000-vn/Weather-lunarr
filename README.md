# Thời tiết và Âm lịch Widget
## Hướng dẫn đưa lên GitHub và Build APK tự động
1. Giải nén toàn bộ thư mục này và push lên repository GitHub của bạn (nhánh `main`).
2. Thay file icon của bạn (`app_icon.png`) vào thư mục `app/src/main/res/drawable/` (nhớ xóa file `app_icon.xml` mẫu đi để tránh trùng tên tài nguyên).
3. Vào tab **Actions** trên GitHub -> chọn **Build Android APK** -> tải file APK ở mục **Artifacts** sau khi build hoàn tất.
